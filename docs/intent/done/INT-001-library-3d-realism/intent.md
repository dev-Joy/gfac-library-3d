# Intent: 성현동작은도서관 3D 실사 재현 (서가배치도·내부 사진 기반)

## 문제 (Problem)
- 현재 3D 장면은 어두운 갈색 톤의 가상 ㄷ자 서가 배치로, 실제 성현동작은도서관의 밝은 실내와 `public/서가배치도_성현.png`의 구역 구분(원서·일반·영C·유·별치 C)을 반영하지 못한다.
- 열람 테이블·PC 파티션 좌석·북카트·자료실 데스크·미디어실 같은 실제 가구가 없어 "실제 도서관"이라는 인상이 약하고, 사진(`public/성현동작은도서관_내부1~3.jpg`)과의 괴리가 크다.

## 제안 결과 (Proposed outcome)
- 배치도 3개 구역(원서 800·원서신간·일반 000~803 / 영C·원서 000~700·일반 800,900·유아 C / C 300~900)이 3D 공간으로 재현되고, 서가마다 실제 분류 표찰(`유`, `원서 000~700`, `일반 800~803` 등)이 보인다.
- 내부 사진과 유사한 밝은 조명·원목 톤·흰 벽·창/블라인드가 적용되고, 열람 테이블·의자·PC 파티션·북카트·자료실 데스크·미디어실 유리문이 배치된다. 디지털정보실 유리벽과 미디어실(ON AIR) 입구 사인까지 포함한다.
- 도서관정보나루(111063) 장서가 KDC·별치 순서(주요 별치 C·유·영C는 섹션 분리)대로 꽂혀 있으며, 책 클릭 시 기존 상세 패널(소장/대출·표지·책소개)이 그대로 동작한다.
- 1인칭 도보 시점으로 자료실 사이를 걸어 다니며 서가·가구를 둘러볼 수 있다(벽·서가 통과 방지).

## 영향 사용자 및 시스템 (Affected users and systems)
- 사용자: 3D로 도서관을 둘러보는 이용자·소개 자료 열람자(데스크톱·모바일 브라우저).
- 시스템: `src/scene/*`(Room·ShelfBay·LibraryCanvas·CameraRig), `src/data/layout.ts`, `src/types.ts`, `scripts/build-shelves.mjs`(서가 그룹 메타), `public/data/shelves.json`, 정보나루 프록시(`vite.config.ts`·`src/api/naru.ts`).

## 제약 (Constraints)
- React 19 + @react-three/fiber + three 스택 유지, 신규 의존성·외부 GLTF 에셋 도입 금지(사용자 승인 없이 설치하지 않음).
- 3D는 브라우저에서 60fps 목표, 책은 기존 instancing 구조를 유지하고 표본 권수 규모를 크게 늘리지 않는다.
- `.env`의 `LIBRARY_API_KEY`는 브라우저로 노출하지 않고 `vite.config.ts` 프록시 주입 방식을 유지한다.
- 배치도는 2D 개념도로 실측 치수가 없으므로 상대 비율·동선 위주로 재현하고, 사진에 없는 구역은 추정으로 채우지 않는다.
- 1인칭 도보는 데스크톱 키보드(WASD)·마우스(시선) 기준으로 구현하고, 모바일은 터치 이동 UI로 대체한다.

## 배경 · 결정 · 참조 (Context handoff)
- 원 요구: `public/`의 png·jpg를 보고 three.js로 성현동작은도서관을 3D로 만들고, `.env`의 도서관정보나루 API로 실제 서가처럼 배치하며, 가구·런 것(집기)을 사진과 유사하게 제작하고 `서가배치도_성현.png`로 서가 배치를 정한다. (출처: 대화 요청)
- D-01: 도서 데이터는 기존 `harvest → build-shelves` 파이프라인을 재사용한다 — 근거: 이미 56,307권 수집·7개 서가 표본 1,976권이 생성되어 있음 / 폐기 대안: 수집 스크립트 신규 작성.
- D-02: 새 에셋 없이 three.js 프리미티브 절차 모델링으로 가구를 제작한다 — 근거: 신규 도구·에셋 미설치 원칙과 오프라인 재현성 / 폐기 대안: GLTF 모델 구매·다운로드.
- D-03: 서가 구역·라벨의 기준은 `서가배치도_성현.png`의 색·표기(원서/일반/영C/유/C)로 삼는다 — 근거: 사용자가 배치도 기준을 명시.
- D-04: 각 베이를 배치도 라벨에 고정하고 장서는 KDC·청구기호 순으로 꽂는다(표본 권수 유지) — 근거: 사용자가 라벨별 고정 배치를 선택 / 폐기 대안: 자동 KDC 배치, 전체 5.6만권 표시.
- 참조: `src/data/layout.ts:146` 현재 서가를 ㄷ자로 자동 배치해 배치도와 무관 / `src/scene/Room.tsx:22` 벽·천장이 어두운 갈색 톤 / `scripts/harvest.mjs:52` `shelf_loc_name`+`separate_shelf_code`로 서가 ID 생성 / `vite.config.ts:15` 정보나루 프록시가 authKey 주입.
- 범위 밖·전제: 실측 도면 기반 정확한 치수, 도서관 운영시스템 연동, 사진 원본을 그대로 붙인 파노라마 배경은 이번 범위가 아니다(사진은 형태·색·분위기 참고용).
